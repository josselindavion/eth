## Objective

Write the script that generates all the Task I deliverables (table, five figures, English text) from the CSVs of a study, and get the first version for the UT19.

## Progress and Notes

### 1. `scripts/post/report_taskI.py`

```
py shpb-ut-equilibrium/scripts/post/report_taskI.py shpb-ut-equilibrium/results/<study>
```

Inputs: `<case>_history.csv` of each run and `<case>_paras.inp` (striker velocity actually used; otherwise the current formula of `make_run.py`). Requires `scipy` (`py -m pip install --user scipy`).

Processing of each run:
- forces F_in, F_out and extensometer strain filtered at 100 kHz (4th-order Butterworth, zero phase);
- output gauge force = S22 × bar area (π × 10² mm²), filtered, shifted in time by 400 mm / 4871 m/s = 82 µs to the specimen (no dispersion correction). Check: at 100 s⁻¹ the shifted gauge force falls exactly on the specimen forces;
- loading start: first instant where F_in > 2 % of its maximum; useful window: from the loading start to 30 % strain (or to the maximum strain);
- R = (F_in − F_out) / F_mean, only where F_mean > 10 % of its maximum.

**Columns of T1** (definitions in `docs/results.md` §5):

| Column | Definition |
|---|---|
| achieved rate | mean slope of the strain between 5 % and min(25 %, 0.8 × max strain) |
| time to 30 % | from the loading start to 30 % strain; empty if never reached |
| equilibrium from strain / after | strain (and time since loading start) from which \|R\| < 5 % until 30 %; empty if never |
| max \|R\| after 5 % | largest filtered \|R\| between 5 % and 30 % |
| max \|dF\| after 5 % | largest \|F_in − F_out\| (kN) over the same window |
| max gauge error after 5 % | largest \|F_gauge − F_out\| / F_max: difference between what the gauge measures and the true specimen force |
| hourglass | ALLAE / ALLIE at the end of the run |

**Definition of the achieved strain rate (window 5–25 %).** The strain rate is not constant during the test (F4), so a single value per run must state on which part of the test it is taken. This value is used to check the striker velocity formula of `make_run.py`, which describes an **established regime**: constant incident wave and roughly constant specimen force (F ≈ 7 kN in the braking term 2F/ρcA). The window is chosen to cover that regime:

| Bound | Value | Reason |
|---|---|---|
| lower | 5 % strain | before: start-up transient. Rise of the incident pulse (≈ 40–60 µs), settling of the specimen shoulders in the pockets (rebound: the rate is even negative for a moment), and specimen force building up from 0 to its maximum, so the braking term 2F/ρcA changes. The force maximum is reached at 5.0 / 5.8 / 7.6 % strain (500 / 100 / 1000 s⁻¹): from there the loading is established |
| upper | min(25 %, 0.8 × max strain) | stop before the end of the useful window. 500 and 1000 s⁻¹ (30 % reached): 0.8 × 30 % = 24 %. 100 s⁻¹: the pulse ends at 18.5 %, so the bound is 14.8 %, which excludes the unloading |

Since the time points are equally spaced, the mean slope over the window is exactly the **secant**: strain gained / time taken.

| Case | Window | Time | Achieved rate |
|---|---|---|---|
| 100 s⁻¹ | 5 → 14.8 % | 2.205 → 3.144 ms | 105 s⁻¹ |
| 500 s⁻¹ | 5 → 24 % | 1.523 → 1.872 ms | 546 s⁻¹ |
| 1000 s⁻¹ | 5 → 24 % | 1.417 → 1.595 ms | 1074 s⁻¹ |

Within the window the rate still increases slightly (529 → 582 s⁻¹ at 500 s⁻¹) because the force drops during necking. The full history is shown in F4.

**Figures** (each saved as PDF for the report and PNG): F1 equilibrium, F2 forces (one panel per rate), F3 stress-strain (A0 = 5 × 1.5 = 7.5 mm²), F4 strain rate (log scale, targets dotted), F5 striker velocity chart. One colour per target rate, the same in every figure.

**Text** (`report.md`, English): simulation and signal processing, table T1, one sentence per run generated from the numbers (e.g. "equilibrium is established at x % strain and holds until…" or "is not maintained: |R| reaches…"), loading speeds with the formula, limitations.
