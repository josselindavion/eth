# 2026-10-20

## Objective

Reorganise where the results are stored, so that every study has one clean, versioned folder with its curves, logs and deliverables, and commit the UT19 results.

## Progress and Notes

### 1. Problem

The fetched results landed in `runs/_submit/<study>/`, the folder used to prepare the input files sent to Euler: looking for results in a "submit" folder made no sense, and inputs and outputs were mixed.

### 2. New organisation

| Folder | Content | Versioned |
|---|---|---|
| `runs/<case_id>/` | input files of a run (generated by `make_run.py`) | no (regenerated) |
| `runs/_submit/` | copies prepared for Euler by `submit_study.py`, disposable | no |
| `results/<study>/<case>/` | `_history.csv`, `_paras.inp`, `.sta`, `.msg`, `_inventory.txt`, `_overview.png` | yes |
| `results/<study>/<case>/<case>.odb` | Abaqus results (≈ 0.7 GB each) | **no**: GitHub refuses files > 100 MB; they stay on the PC next to the other results |
| `results/<study>/report/` | T1, F1–F5 (.pdf + .png), `report.md` | yes |

Changes:
- `fetch_study.py` unpacks into `results/<study>/`; new option `--odb all` copies every `.odb` of the study;
- `extract_study.sh` skips a run that has already been extracted (CSV newer than the `.odb`) and packs the `_paras.inp` (striker velocity of each run, needed by `report_taskI.py`); the Slurm logs and `cases.txt` are no longer brought back;
- `.gitignore`: `.sta` and `.msg` tracked in `results/` (run logs), `.odb` never;
- `plot_case.py` and `report_taskI.py` write next to the CSVs, so after `fetch_study.py` and the two plotting scripts everything is already in place: only `git add` + `commit` + `push` remain;
- README: new section "Où sont les résultats" and the full chain (step 6: deliverables); `docs/results.md` §5: signal processing and indicators; obsolete `.gitkeep` files removed.

### 3. Full chain for a study (PC, Git Bash, root of the repo)

```
py shpb-ut-equilibrium/scripts/hpc/submit_study.py taskI                          # prepare, copy, launch on Euler
py shpb-ut-equilibrium/scripts/hpc/fetch_study.py <study> --clean --odb all      # extract and retrieve
py shpb-ut-equilibrium/scripts/post/plot_case.py shpb-ut-equilibrium/results/<study>      # control figures
py shpb-ut-equilibrium/scripts/post/report_taskI.py shpb-ut-equilibrium/results/<study>   # deliverables
git add shpb-ut-equilibrium/results && git commit -m "..." && git push
```

Follow-up on Euler: `squeue -u $USER` and `tail -n 3 $SCRATCH/<study>/*/*.sta` (`-n` is required with several files).
