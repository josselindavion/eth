# 2026-10-08

## Objective

Set up the Task I project folder and get the geometry of the whole SHPB bench into Abaqus/CAE through a script, placed in a common global frame and cut to a half model.

## Progress and Notes

### 1. Task I and project folder

Task I: simulate the automated SHPB with load inversion device (LID) for uniaxial tension (UT) specimens with a short (19 mm) and a long (40 mm) gauge section, at nominal strain rates of 100, 500 and 1000 s⁻¹; assess whether quasi-static force equilibrium is reached and find the loading speeds needed to reach 30 % engineering strain. Experiments on the automated SHPB will follow and be compared with the simulations.

The old `task1/` folder was replaced by a dedicated project folder `shpb-ut-equilibrium/`, organised so that each step of the work is a script and the model itself is plain text (lab convention: Abaqus/CAE is only used to mesh, the run is assembled from text files with `*INCLUDE`):

| Folder | Content |
|---|---|
| `cad/native/`, `cad/step/` | SolidWorks parts and their STEP exports |
| `model/geometry/` | one `.geo` per piece (nodes, elements, sets) |
| `model/materials/` | one `.dat` per material |
| `model/templates/` | main `.inp` and `_paras.inp` templates |
| `scripts/cae/` | Abaqus/CAE scripts (Python 2.7) |
| `scripts/pre/`, `scripts/hpc/`, `scripts/post/` | Python 3 scripts: preparation, cluster, post-processing |
| `studies/taskI/cases.csv` | test matrix: UT19 / UT40 × 100 / 500 / 1000 s⁻¹ |
| `runs/` | generated run folders (not versioned) |
| `docs/` | documentation of the model, written as tables |

Units for the whole project: mm, N, s, MPa, t/mm³. Case naming: `<specimen>_R<strain rate on 4 digits>_<index>`, e.g. `UT19_R0500_00`.

The continuum mechanics review (`MMC/rappels-mmc-task1.md`) and the notes of 1 and 7 October were also committed.

### 2. CAD of the bench

Available SolidWorks parts: the two specimens (UT and NT20 "Christmas tree" clamping), the output bar and the load inverter (pusher). The striker and the input bar are plain Ø20 mm cylinders (striker 5000 mm, input bar 6010 mm, Beerli et al. 2026) and are created directly in the script.

**Problem: the `.SLDPRT` files cannot be imported** ("The file version is not supported": the SolidWorks version is newer than what Abaqus 2023 reads). Solution: export every part as STEP AP214 into `cad/step/`. The specimen sketch was first extruded to 1.5 mm in SolidWorks (along +Z, z = 0 to 1.5) → `XMas_UT_t1p5.step`.

### 3. Placement in a global frame (`docs/assembly.md`)

The specimen is pulled along **Y** (all bar axes along Y). The placement was worked out from the CAD coordinates of the pockets and of the bar axes:

| Instance | Rotation | Translation (mm) |
|---|---|---|
| PUSHER | +90° about X | none |
| INPUT_BAR | +90° about X | (0, 0, 7.85) |
| OUTPUT_BAR | +90° about X | (0, 155.713, 29.35) |
| UT19 (specimen) | +90° about Z | (356.2728, −1357.7622, 28.6) |
| STRIKER | +90° about X | (0, −6010, 7.85) |

Checks:
- the output bar axis is 21.5 mm above the input bar axis (Beerli 2026, fig. 5a);
- both pockets open upward and their floors are at the same height Z = 28.6 mm, where the specimen simply lies (I first wrongly thought the specimen was sandwiched between the pusher and the output bar);
- the specimen is centred in both pockets (tips at Y = 124.013 and 201.700 mm).

### 4. First version of `scripts/cae/build_bench.py`

Run in Abaqus/CAE with File → Run Script. It imports the STEP files, creates the striker and the input bar, and positions the five instances with the table above.

**Half model.** As in the lab's own models (Roth 2015, Beerli 2026), the bench is symmetric about the plane X = 0, so only X ≥ 0 is kept: each piece is placed, then cut with a box covering X < 0 (`InstanceFromBooleanCut`). The script then checks the X extent of every half part (must start at X = 0). A symmetry condition on the cut plane will be added in the input file.

`.gitignore` updated so that `.cae`, `.jnl` and the other files generated by Abaqus are not versioned (they are regenerated by the script).
